# Life Balance Frontend

This is a Vite + React frontend scaffold for the Life Balance app backend.

Quick start:

- cd frontend
- npm install
- npm run dev

The frontend expects the backend running at http://localhost:8080 and uses session cookies (credentials: include).

Routes:
- /login - login
- /register - register
- /app - protected dashboard

Notes: This is a minimal scaffold implementing the requested features (auth via session, month picker, expenses/incomes tabs). Further polish can be done (dialog forms, toasts, charts).
